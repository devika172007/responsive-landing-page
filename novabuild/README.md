# NovaBuild – Responsive React Landing Page

## 📖 Description

NovaBuild is a responsive landing page built using React and Vite. It demonstrates reusable React components, React Router navigation, and a clean responsive design.

## ⚙️ Installation

```bash
git clone https://github.com/devika172007/responsive-landing-page.git

cd responsive-landing-page

cd novabuild

npm install

npm run dev
```

---

## 🏗️ Build

```bash
npm run build
```
