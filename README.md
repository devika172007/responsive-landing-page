# NovaBuild – Responsive Landing Page

A modern, fully responsive landing page built with semantic HTML5, CSS3 (Flexbox + Grid), and vanilla JavaScript.

> Add your GitHub Pages link here after deployment

## 📋 Project Overview
This is a responsive landing page built as part of the VertexMind internship task. It includes:
- **Header** – Fixed navigation with mobile hamburger menu
- **Hero Section** – Animated headline, CTA buttons, and stats
- **Features Section** – 6-card responsive grid
- **How It Works** – 4-step process layout
- **Footer** – Multi-column responsive footer

## 🛠️ Tech Stack
- HTML5 (Semantic elements: `header`, `nav`, `section`, `footer`)
- CSS3 – Flexbox, CSS Grid, Media Queries, CSS Variables, Animations
- Vanilla JavaScript – IntersectionObserver scroll reveals, mobile menu toggle

## 📱 Responsive Breakpoints
| Breakpoint | Layout |
|---|---|
| < 480px | Single column, stacked footer |
| 480px – 768px | 2-column footer, flexible grids |
| > 768px | Full desktop layout |
